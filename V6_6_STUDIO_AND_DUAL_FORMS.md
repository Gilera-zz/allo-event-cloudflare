# Allo Event V6.6

- Two explicit inquiry modes share one booking component: Staffing / Quote.
- All existing CTAs select the correct mode before scrolling.
- Users can switch mode inside the booking section without leaving the page.
- Staffing and quote modes use different copy, labels and category options while saving to the same leads table.
- 3D section redesigned to visually connect Allo Event with Allo Studio: deep navy product surface, gold accent, design/cloud/production rail and a richer Studio preview.
- All Studio CTAs point to https://beta.studio.alloevent.se.
- No database migration required.
